# אופציות ומכשירים פיננסיים

אתר הקורס: https://shaytsaban.github.io/options-financial-instruments/

- `index.html`: דף הבית.
- `lectures/lecture-1/`, `lectures/lecture-2/`: מצגת וסיכום PDF לכל שיעור. שיעור 2 ממשיך את המבוא מהאופציה והלאה.
- `materials/`: סילבוס וקובצי תרגול.
- `_build/`: מקורות הבנייה. `python3 build_deck.py 1` (או 2), `python3 test_deck.py ../lectures/lecture-1/presentation.html`, `python3 build_summary.py 1` (או 2), `python3 build_syllabus.py`, `python3 build_xlsx.py` (קובצי התרגול של שני השיעורים), `python3 build_hub.py`. פונטי David נטענים מ-`../iit-build/fonts` ואינם נשמרים כאן.
